# Atelier — Premium Author Website (scaffold)

This is a handcrafted luxury website scaffold for *Atelier* (Comonline.com). It uses a black, editorial theme and includes modular sections ready for your images and copy.

Quick start (from project root):

```powershell
# start a simple static server
cd "c:\Users\USER 2\Atelier"
py -3 -m http.server 8000

# then open http://localhost:8000 in your browser
```

Files of interest:
- index.html
- assets/css/styles.css
- assets/js/app.js
- assets/img/product-1.svg (placeholder)

Replace the SVG placeholders with the three Amazon product images and update copy as needed.
